# DoorIQ

A configure-price-quote (CPQ) demo for security screen door manufacturers, built by **Analytics with Shlok** (analyticswithshlok.com).

- Field measurements in, rendered door out
- Grouped bill of materials, nested cut list on 24' stock, shop routing
- Rules engine with pass / applied / review / blocked results
- Customer price lists, margin floor with manager approval
- Customer-ready quotation preview
- **Play demo** button runs a scripted walkthrough for screen recording (Esc to stop)

Saguaro Iron Works, its parts, costs and prices are fictional.

Single static file: `index.html`. Deploys as-is on Vercel (no build step).
